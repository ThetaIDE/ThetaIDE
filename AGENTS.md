# Project agent guidance

For component releases to Theta Hub, follow [the production release workflow](THETA_HUB_RELEASE_WORKFLOW.md). It covers the package, registry, published feeds, and client verification. Follow any additional applicable workspace guidance as well.

Configuration UI changes must follow [the shared parameter form conventions](docs/CONFIG_PARAMETER_FORMS.md). Apply these conventions to every ordinary config box; the Methods box has a specialized layout. Extend the shared controls rather than implementing a new pattern for each box.
